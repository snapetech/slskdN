Share scans now stream file and directory enumeration and checkpoint the share database after maintenance. Browse windows large peer trees without a folder cutoff. Share aliases accept `]` in local paths, Relay agents normalize controller URL slashes, and nested deployments revalidate the UI index. Disk logs are enabled by default with 30-day retention; set `logger.disk: false` to disable them.
