# Archive

This directory contains historical plans, audits, incident notes, status
snapshots, and completed workstream records.

Archived files are not current instructions. Prefer the active documentation
index at `docs/README.md`, current configuration docs, release checklists, and
feature-specific user guides when validating present behavior.

When moving active documents here:

- keep the original date in the filename or folder when possible;
- update active references that should still point to the archived record;
- avoid linking archived plans from active docs unless the link is explicitly
  historical context.
